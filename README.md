# Печник Иван — коммерческий сайт мастера

Современный адаптивный сайт для частного мастера по строительству кирпичных печей, каминов и уличных комплексов в Пензе и Пензенской области.

Проект разработан с акцентом на визуальную подачу работ, удобство мобильного использования, конверсию в обращение к мастеру и техническую SEO-подготовку.

---

## Preview

> Production URL будет добавлен после публикации проекта.

Основная задача сайта — за несколько секунд объяснить посетителю:

- кто мастер;
- какие работы он выполняет;
- какие проекты уже реализованы;
- от чего зависит стоимость;
- как получить консультацию;
- как отправить мастеру предварительные данные проекта.

---

## Возможности

### Портфолио

- адаптивная галерея выполненных работ;
- фотографии хранятся локально в проекте;
- интерактивный Lightbox;
- просмотр фотографий в полноэкранном режиме;
- поддержка desktop и mobile;
- hover-эффекты на desktop;
- закрытие Lightbox через кнопку, фон и Escape.

### Калькулятор

Пошаговый предварительный калькулятор:

1. выбор типа проекта;
2. выбор объекта;
3. дополнительные параметры;
4. формирование предварительных данных;
5. отправка подготовленного сообщения мастеру через Telegram.

Калькулятор намеренно не показывает выдуманные цены — окончательная стоимость рассчитывается мастером индивидуально.

### Консультация

CTA размещены в ключевых точках сайта:

- Hero;
- Header;
- блок технологий;
- стоимость;
- калькулятор;
- портфолио;
- консультация;
- контакты.

Основная задача CTA — максимально короткий путь от интереса пользователя до связи с мастером.

## SEO

Сайт подготовлен с учётом технического SEO.

Реализовано:

- корректный `lang="ru"`;
- один H1;
- логичная структура H2/H3;
- семантические HTML5-элементы;
- `title`;
- `meta description`;
- Open Graph;
- Twitter Card;
- canonical;
- robots.txt;
- sitemap.xml;
- Schema.org JSON-LD;
- FAQPage;
- Person;
- HomeAndConstructionBusiness;
- WebSite;
- корректные `alt` для изображений;
- внутренние якорные ссылки;
- отдельная 404-страница;
- `noindex, follow` для 404;
- подготовка абсолютных URL через `VITE_SITE_URL`.

SEO-файлы генерируются автоматически после production build.

---

## Производительность

Для изображений реализовано:

- `loading="eager"` для Hero;
- `fetchPriority="high"` для Hero;
- preload Hero-изображения;
- `loading="lazy"` для изображений ниже первого экрана;
- `width` / `height`;
- `decoding="async"`.

Layout рассчитан на отсутствие скачков при загрузке изображений.
